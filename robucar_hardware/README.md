# robucar_hardware

## 1) Overview

`robucar_hardware` provides the live `ros2_control` hardware plugin for the Robucar mobile base.

It specializes the generic `2AS4WD` hardware abstraction from `romea_mobile_base_hardware` and connects it to the Robucar low-level controller through the Pure communication protocol.

The exported plugin is:

| Plugin | Base class | Mobile base architecture |
|---|---|---|
| `robucar_hardware/RobucarHardware` | `HardwareSystemInterface2AS4WD` | `2AS4WD` |

## 2) Hardware concept

`RobucarHardware` is loaded by `controller_manager` from the `<ros2_control>` description generated by `robucar_description`.

At runtime, it:

1. reads the Robucar `ros2_control` hardware information;
2. creates the `HardwareInterface2AS4WD` command and state interface mapping;
3. loads front and rear wheel radii used to convert wheel angular speeds;
4. connects to the Robucar low-level controller through the Pure client;
5. registers for feedback notifications from the robot;
6. converts controller-side wheel angular speed commands into Robucar wheel linear speed commands;
7. sends front and rear axle steering commands and four wheel speed commands;
8. decodes robot feedback notifications;
9. converts received wheel speed and steering feedback into `ros2_control` state interfaces;
10. sends a null command and stops notifications when the interface is disconnected.

From the controller point of view, this behaves like a standard mobile base hardware plugin: `romea_mobile_base_controllers/MobileBaseController2AS4WD` writes front and rear axle steering commands and four wheel speed commands, then reads steering and wheel speed feedback from state interfaces to compute odometry.

## 3) Pure communication

The current implementation connects to the Robucar low-level controller with:

| Parameter | Value |
|---|---|
| Robot IP | `192.168.1.2` |
| Port | `60000` |
| Pure target | `2` |

The hardware plugin sends:

* drive enable information;
* front and rear axle steering commands;
* front, rear, left and right wheel linear speed commands;
* null commands when the interface is connected or disconnected.

It receives:

* front and rear axle steering angle feedback;
* front, rear, left and right wheel linear speed feedback.

Wheel speeds are exchanged with the Robucar low-level controller as linear speeds and exposed to `ros2_control` as wheel angular speeds.

## 4) Relation with other packages

`robucar_hardware` is the live hardware specialization of the Robucar mobile base:

* `robucar_description` selects `robucar_hardware/RobucarHardware` in `live` mode;
* `romea_mobile_base_hardware` provides the reusable `2AS4WD` hardware abstraction;
* `romea_mobile_base_utils` provides helpers used to read `hardware_interface::HardwareInfo`;
* `romea_mobile_base_controllers` sends commands through the exported `ros2_control` interfaces;
* `robucar_bringup` starts the controller manager and loads this hardware plugin in live mode.
